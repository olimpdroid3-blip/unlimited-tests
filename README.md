# Tower Keeper

Новый проект GvG Вежі (Watcher of Realms)

Создай новый проект с нуля.

Используй тёмную стилистику, цвета, шрифты и общий дизайн максимально похожие на существующий проект только в стиле минимализм. Шапку страницы оставить практически без изменений.

База данных

Использовать Supabase как единственную базу данных.

Создать таблицу для хранения информации по башням.

Поля:

tower_id

nickname

awakenings

notes

updated_at

Каждая запись соответствует одной фиксированной позиции башни.

Главная страница

Сохранить стиль как в существующем проекте.

На странице расположить 4 вертикальных столбца.

В каждом столбце расположить по 12 кнопок.

Первый столбец

1.1.1

1.1.2

1.2.1

1.2.2

1.3.1

1.3.2

1.4.1

1.4.2

1.5.1

1.5.2

1.6.1

1.6.2

Второй столбец

2.1.1

...

2.6.2

Третий

3.1.1

...

3.6.2

Четвертый

4.1.1

...

4.6.2

Всего должно получиться 48 кнопок.

Цвет кнопок

По умолчанию все кнопки имеют темный цвет.

Если для башни существует запись в базе данных —

кнопка автоматически становится зелёной.

Если запись удалить —

кнопка снова становится чёрной.

Это должно происходить автоматически после любого изменения.

Работа кнопок

Каждая кнопка является одновременно и просмотром и редактированием.

Например пользователь нажимает

3.4.2

Открывается модальное окно.

Модальное окно

Заголовок

🏰 Башня 3.4.2

Поля

Нік

Пробуди

Примітки при проходці

Если запись уже существует —

все поля автоматически заполняются сохраненными значениями.

Кнопки

💾 Зберегти

Сохраняет изменения в Supabase.

После сохранения:

закрывает окно;

обновляет цвет кнопки на зелёный.

🗑 Видалити

Удаляет запись полностью из базы данных.

После удаления

закрывает окно;

кнопка снова становится чёрной.

Перед удалением обязательно показать подтверждение

"Видалити запис?"

❌ Закрити

Просто закрывает окно.

Архив

Внизу страницы добавить большую кнопку

📦 Архів

При нажатии открыть отдельную страницу.

В архив автоматически попадают все записи после выполнения массовой очистки.

Архив только для просмотра.

Редактирование архива запрещено.

Массовая очистка

В самом низу главной страницы расположить большую красную кнопку

🗑 Видалити всі записи

Перед выполнением показать подтверждение

"Всі записи будуть перенесені до архіву. Продовжити?"

После подтверждения

Все текущие записи копируются в архив.

Основная таблица полностью очищается.

Все 48 кнопок снова становятся чёрными.

Интерфейс

Сделать максимально удобным для телефона.

Минимум прокруток.

Минимум лишних кнопок.

Минимум текста.

Всё должно открываться через модальные окна.

Анимации

Использовать плавные современные анимации.

Модальные окна открываются плавно.

Изменение цвета кнопки происходит плавно.

Технические требования

React

TanStack Router

Supabase

Полностью адаптивный дизайн

Корректная работа на Android

Не использовать Telegram-бота.

Не создавать лишних страниц.

Код должен быть чистым и хорошо структурированным.
